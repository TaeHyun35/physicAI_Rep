1. 문제 정의 (Problem Statement)
제품 개요. 에코소트는 투입구에 재활용품을 하나씩 넣으면 카메라와 센서로 품목을 인식해 플라스틱, 캔, 종이, 기타 4개 통으로 자동 분류하는 탁상형 장치입니다.
주요 입력 데이터: 라이트박스 내부 카메라 이미지, 금속 감지 센서(유도형 근접 센서) 신호, 무게(로드셀), 투입 감지 센서 신호
주요 출력(행동): 서보모터로 회전 슈트와 개폐판을 움직여 해당 통에 투하, LED·LCD로 분류 결과 표시, 대시보드에 통계 기록, 통이 가득 차면 알림
현재 문제. 분리배출 기준이 품목마다 달라 사용자가 헷갈리고, 잘못 배출된 품목이 재활용품에 섞입니다. 혼입이 많으면 선별장에서 다시 손으로 골라내야 하고, 일부는 재활용되지 못하고 소각·매립됩니다. 사무실이나 학교 분리수거함은 이용자가 많아 오류가 더 자주 발생합니다. (가정)
기존 방식의 한계.
안내문·스티커: 분리배출 표시를 읽지 않거나 이해하지 못하면 효과가 없습니다.
사람의 재분류: 미화원이나 관리자가 수거함을 다시 정리해야 해서 시간과 비용이 듭니다.
산업용 AI 선별 로봇: 대당 수억 원대라 선별장 규모에서만 경제성이 있고, 배출 단계(가정·사무실)에는 쓸 수 없습니다.
핵심 가치. 배출 시점에 품목을 자동으로 판별해 올바른 통에 넣고, 결과를 화면으로 보여 줘 사용자의 분리배출 습관도 함께 교정합니다. 모든 처리는 기기 안(엣지)에서 이뤄져 인터넷 없이 동작하고, 촬영 이미지가 외부로 나가지 않습니다.
AI가 필요한 이유. 같은 페트병이라도 라벨, 구김, 색, 내용물 잔여 여부에 따라 모양이 크게 달라 색이나 크기 같은 고정 규칙으로는 구분이 어렵습니다. 딥러닝 분류 모델이 다양한 외형을 학습하고, 금속·무게 센서를 결합해 이미지만으로 헷갈리는 경우(은색 플라스틱과 캔, 코팅 종이컵과 플라스틱 컵)를 보완합니다.
2. 사용자 시나리오 (User Scenario)
주요 사용자는 가정·사무실의 일반 이용자와 장치를 관리하는 운영자(개발자 본인)입니다.
설치. 운영자가 에코소트 본체(라이트박스 + 회전 슈트)를 수거통 4개 위에 올리고 전원을 연결합니다. 첫 부팅 시 빈 라이트박스를 촬영해 배경 이미지를 저장하고, 화이트밸런스와 노출을 고정합니다.
데이터 수집. 이용자가 투입구에 품목 1개를 넣으면 적외선 투입 감지 센서가 반응합니다. 0.3초 안정화 후 카메라가 1장을 촬영하고, 금속 감지 센서 값과 로드셀 무게를 동시에 읽습니다.
분석. 배경 차분으로 물체 영역을 찾아 잘라내고(ROI), 크기와 색을 정규화한 뒤 분류 모델(MobileNetV3 또는 YOLOv8n-cls, TensorRT FP16)에 넣습니다. 모델은 4개 클래스(플라스틱, 캔, 종이, 기타)의 확률을 출력합니다.
판정 생성. 이미지 확률과 센서 값을 규칙으로 결합합니다. 예를 들어 금속 감지가 켜지면 캔으로 확정하고, 최고 확률이 0.6 미만이면 '확인 필요'로 분류합니다. 투입부터 판정까지 목표는 0.5초 이내입니다.
장치 제어. 판정 결과에 따라 아두이노(ESP32)가 서보모터로 회전 슈트를 해당 통 방향으로 돌리고 개폐판을 열어 투하합니다. LCD에 "플라스틱 – 라벨을 떼면 더 좋아요" 같은 결과와 팁을 표시합니다. '확인 필요'면 LED가 노란색으로 켜지고 이용자가 버튼 4개 중 하나를 눌러 직접 선택하며, 이 선택은 정답 라벨로 저장됩니다.
결과 확인 및 후속 행동. 운영자는 웹 대시보드에서 일별 투입 수, 품목 비율, 저신뢰 판정 목록, 통 적재량을 확인합니다. 통이 80% 차면 알림을 받아 비우고, 주 1회 저신뢰 이미지를 검수해 재학습한 모델을 배포합니다.

4. 기술 스택 (Technology Stack)
추론과 데이터 저장은 모두 Jetson 보드 안에서 처리하고, 개인이 구하기 쉬운 부품과 오픈소스만 사용합니다.

5. 개발 범위 / 비범위 (Scope)
1인 8주 개발 기준으로, 1개 품목 투입부터 분류·투하·통계·재학습까지의 전체 루프를 완성하는 데 집중합니다. (가정)
개발 범위 (In Scope)
실시간 이미지 분류: 배경 차분 기반 ROI 추출과 4개 클래스 분류를 0.5초 이내에 수행합니다.
센서 융합 판정: 금속 감지·무게 값을 이미지 확률과 규칙으로 결합해 최종 판정합니다.
장치 제어: 서보 2개로 회전 슈트와 개폐판을 움직여 해당 통에 투하하고, 투하 성공 여부를 확인합니다.
사용자 피드백: LCD에 결과와 배출 팁을 표시하고, '확인 필요' 시 버튼 4개로 직접 선택받습니다.
데이터 저장: 모든 판정의 이미지, 확률, 센서 값, 최종 라벨을 SQLite와 로컬 폴더에 저장합니다.
대시보드: Streamlit으로 일별 투입량, 품목 비율, 정확도 추이, 통 적재량, 저신뢰 이미지 검수 화면을 제공합니다.
알림 기능: 통 80% 적재, 서보 오류, 카메라 연결 끊김을 텔레그램으로 알립니다.
재학습 파이프라인: 검수된 데이터로 재학습하고, 테스트셋 성능 비교 후 모델을 교체하며 이전 모델로 롤백할 수 있습니다.
개발 제외 범위 (Out of Scope)
여러 품목 동시 투입: 한 번에 1개 품목만 처리합니다. 다중 물체 검출은 2차 과제로 미룹니다.
유리병 분류: 투하 시 깨질 위험이 있어 1차 버전에서는 '기타'로 처리합니다.
세척·라벨 제거 등 전처리 동작: 내용물 세척이나 라벨 분리는 하지 않고 안내 문구만 표시합니다.
컨베이어 연속 처리: 선별장 수준의 처리량(초당 수 개)은 목표가 아닙니다.
모바일 앱: 알림은 텔레그램, 통계는 웹 대시보드로 대체합니다.
클라우드 학습·저장: 학습은 Colab이나 개인 PC에서 수동으로 하고, 클라우드 자동 학습 파이프라인은 만들지 않습니다.
사용자 계정·권한 관리: 운영자 1명 기준으로 로그인 기능을 두지 않습니다.
