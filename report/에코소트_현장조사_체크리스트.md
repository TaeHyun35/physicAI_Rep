## 샘플 이미지 수집 지침

### 1. 클래스별 최소 촬영 장수
- 학습용: 클래스당 최소 100장 (플라스틱, 캔, 종이, 기타)
- 테스트용: 클래스당 100장을 별도 품목으로 촬영 (학습용과 같은 물건 사용 금지)
- 빈 라이트박스 배경: 시간대별(오전·오후·밤) 각 10장

### 2. 촬영 조건 조합 (16가지)
- 조명: 켬(L1) / 끔(L0) ※ 끔은 LED 고장·외부광 상황 대비 강건성 테스트용
- 청결: 깨끗함(C0) / 오염(C1)
- 형태: 원형(S0) / 구겨짐(S1)
- 시점: 정면(F) / 측면(S)
- 각 조합마다 클래스당 최소 6장 → 클래스당 약 100장

### 3. 헷갈리는 품목 별도 촬영 (품목당 20장, 위 조건 조합 섞어서)
- 은색 플라스틱 용기, 코팅 종이컵, 알루미늄 호일 포장, 은박 과자봉지
- 투명 일회용 컵과 투명 페트병, 종이팩, 스프링 노트
- 금속 센서 오작동 품목 (E-02에서 체크한 것)

### 4. 파일명 규칙
`클래스_품목_조건_번호.jpg`

예시:
- `plastic_petclear_L1-C0-S1-F_0001.jpg`
- `can_beer_L0-C1-S0-S_0012.jpg`
- `confuse_coatedcup_L1-C0-S0-F_0003.jpg`

규칙:
- 클래스: plastic / can / paper / etc / confuse (헷갈리는 품목)
- 촬영 시 금속 감지 값과 무게를 같은 이름의 .txt 파일로 함께 저장
- 모든 물건에 고유 물체 ID(예: P-0042)를 붙여 별도 목록으로 관리
